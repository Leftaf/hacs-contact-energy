# Contact Energy Home Assistant Integration

Custom HACS integration for Home Assistant that automatically retrieves hourly and daily electricity consumption data from your **Contact Energy** account in New Zealand.

### Key Features
* **Energy Dashboard Integration:** Automatically feeds historical usage statistics directly into the native Home Assistant Energy Dashboard.
* **Sensor Tracking:** Exposes sensors for electricity consumption, daily usage, and account metrics.
* **Automated Sync:** Periodically polls the Contact Energy API to ensure up-to-date power monitoring and tracking.
